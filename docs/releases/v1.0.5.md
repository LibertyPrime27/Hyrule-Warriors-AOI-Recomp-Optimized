**Hyrule Warriors AOI Recomp Optimized 1.0.5** lets you choose the button that opens the menu, and clear any binding.

## What's new

- **Open menu is now a binding.** It has its own row in **Esc → Controls**, so you can choose which key or controller button opens and closes the menu.
  - On the keyboard it stays **Esc** by default.
  - Controllers have no menu button by default, so no game button is taken. Bind one if your controller has a spare button.
  - Holding a controller's Open menu button for half a second presses **Minus** (the map) instead, so binding it to Back or Minus still leaves you the map.
  - In co-op, each player can set their own.
- **Leave unbound.** The "Press a key" window has a **Leave unbound** button that leaves the selected cell empty, so that action has no key or button.

## Updating from 1.0.4

Extract 1.0.5, open **Hyrule Warriors AOI Recomp Optimized Compiler.exe**, choose the same NUP and output folder, and click **Compile / update**. Saves, settings, your bindings and your shader cache are kept.

## Using it

Download the ZIP below, extract all of it, open **Hyrule Warriors AOI Recomp Optimized Compiler.exe**, choose your own game NUP and an output folder, then click **Compile / update**. Nothing else needs installing.

> Bring your own matching game files. This ZIP contains no game, keys, firmware or artwork.

## Known limits

- The first time a scene loads, a hitch of up to about a second remains while its small graphics shaders translate.
- Some battles don't allow two players; the game decides where co-op is available.
- 90 and 120 FPS speed up the whole game (1.5× / 2×). For smooth motion at normal speed, play at 60 FPS with frame generation such as Lossless Scaling LSFG 2×.

## Requirements

- Windows 10/11 x64, an AVX2 CPU and a Vulkan GPU (32 GiB RAM recommended)
- At least 20 GiB of free space for the output
- Hyrule Warriors: Age of Imprisonment, title 04003F40232DE000, version 1.0.3 (NCM 196608), as a NUP
