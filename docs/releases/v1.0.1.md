**Hyrule Warriors AOI Recomp Optimized 1.0.1** fixes compiling. **Use this instead of 1.0.0.** In 1.0.0 the final link step failed with `clang: error: no such file or directory: '@work/build/hwaoi196608/Hyrule'`, because the game's new name has spaces and the link command quoted its path twice. Nothing else changes from 1.0.0.

## Fixes

- **Compiling finishes again.** The game links as `Hyrule Warriors AOI Recomp Optimized.exe`, with your game's cover as its icon. A new test now runs the real link command on a name with spaces.
- **New builds get a folder named after the project.** When you pick a parent folder, the compiler creates `Hyrule Warriors AOI Recomp Optimized` inside it instead of `HWAoI-Game`. Existing output folders keep working.

## Already tried 1.0.0?

Extract 1.0.1, open **Hyrule Warriors AOI Recomp Optimized Compiler.exe**, choose the same NUP and the same output folder, then click **Compile / update**. Everything 1.0.0 already compiled is reused, so it goes straight to the link step.

## Using it

Download the ZIP below, extract all of it, open **Hyrule Warriors AOI Recomp Optimized Compiler.exe**, choose your own game NUP and an output folder, then click **Compile / update**. Nothing else needs installing.

> Bring your own matching game files. This ZIP contains no game, keys, firmware or artwork.

## What's in Hyrule Warriors AOI Recomp Optimized

- **Combat runs about 3–4× faster.** Crowded fights went from 13–18 FPS to about **57 FPS** average (RTX 3080 / i9-10850K, 1080p).
- **Seamless loading.**
  - Shader pipelines build in the background.
  - Game files are verified once instead of on every launch.
  - A loading window with a progress bar replaces the black startup screen.
- **DLC and update support.** Merged NUPs compile directly; the optional **Update file** and **DLC file** fields take separate NUPs.
- **Your game's cover as the icon.** It is read from your own NUP at compile time.

## Frame rate

90 and 120 FPS can be selected, but **they speed up the whole game (1.5× / 2×)**. For smooth motion at normal speed, play at **60 FPS** with frame generation, such as Lossless Scaling LSFG 2×.

## Requirements

- Windows 10/11 x64, an AVX2 CPU and a Vulkan GPU (32 GiB RAM recommended)
- At least 20 GiB of free space for the output
- Hyrule Warriors: Age of Imprisonment, title 04003F40232DE000, version 1.0.3 (NCM 196608), as a NUP
