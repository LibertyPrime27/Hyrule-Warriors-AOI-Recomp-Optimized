**Hyrule Warriors AOI Recomp Optimized 1.0.6** uses less memory, so it runs reliably on 16 GB PCs, and no longer freezes the first time a move plays.

## What's new

### No freeze the first time a move plays

- A new move's effects use compute shaders the game hasn't run before. Their pipelines used to be built the moment the move played, freezing the game for **9 to 13 seconds** (measured).
- Now they're built in the background as soon as the shaders translate during loading. In a test with empty caches, 128 were built ahead, no move had to wait, and the worst hitch was 0.8 s.

### Less memory, built for 16 GB PCs

- **Upstream memory update** by Ksora25 from HWAoI Recomp:
  - compact command records (about 31 % smaller);
  - compressed shader-program source (about 166 MiB saved);
  - smaller allocation pools and background freeing.
- **Idle command copies are compressed.** Copies of command lists the game no longer reads are compressed in the background and unpacked if they're ever needed again. After four minutes of play, 793 MiB of copies took 104 MiB.
- **Unused shader code is dropped** after a minute and reloaded from the shader cache if needed (115 MiB freed in play).
- **No spare Vulkan blocks in system RAM.**
- **Automatic low-memory mode.** If Windows can't back the game's memory (for example 16 GB of RAM with a small or disabled page file), the game commits its heap only as it's used, about 1.4–2 GB less. It stutters more while loading, so PCs with enough room don't use it. The log says which mode was chosen; `TOTK_LAZY_HEAP=0` or `1` forces either.

## Updating from 1.0.5

Extract 1.0.6, open **Hyrule Warriors AOI Recomp Optimized Compiler.exe**, choose the same NUP and output folder, and click **Compile / update**. Saves, settings, bindings and your shader cache are kept.

## Using it

Download the ZIP below, extract all of it, open **Hyrule Warriors AOI Recomp Optimized Compiler.exe**, choose your own game NUP and an output folder, then click **Compile / update**. Nothing else needs installing.

> Bring your own matching game files. This ZIP contains no game, keys, firmware or artwork.

## Known limits

- The first time a scene loads, a hitch of up to about a second remains while its graphics shaders translate.
- About one frame in twenty can take 20–25 ms instead of 16.7 ms in busy scenes. This is the game's CPU work and predates this release.
- Some battles don't allow two players; the game decides where co-op is available.
- 90 and 120 FPS speed up the whole game (1.5× / 2×). For smooth motion at normal speed, play at 60 FPS with frame generation such as Lossless Scaling LSFG 2×.

## Requirements

- Windows 10/11 x64, an AVX2 CPU and a Vulkan GPU (16 GiB RAM minimum, 32 GiB recommended)
- At least 20 GiB of free space for the output
- Hyrule Warriors: Age of Imprisonment, title 04003F40232DE000, version 1.0.3 (NCM 196608), as a NUP
