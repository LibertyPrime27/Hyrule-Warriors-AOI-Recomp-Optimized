**Hyrule Warriors AOI Recomp Optimized 1.0.2** fixes the dark caves and brings lower memory use.

## Fixes and improvements

- **Lighting fixed: caves are no longer pitch black.** Areas lit only by local lights (torches, crystals, glowing objects) rendered almost black. The game keeps its light list and light parameters in *buffer textures*, which the port never read, so every local light contributed nothing.
  - The runtime now binds buffer textures as real texel buffers over the game's memory.
  - The shader translator now recognises how the light shaders fetch from them.
  - In the tested cave the blank texture bindings went from 292 to 0, and lighting matches the original game.
- **Lower memory use.** This release includes the upstream HWAoI Recomp memory update by Ksora25:
  - command records are packed to their used size
  - the upload-batch and timestamp caches are bounded
  - the query pool is released at shutdown

  Upstream measured a 137 MiB lower private-memory peak in the opening scene, with no FPS change.
- **No startup loading window.** The loading bar window added in 1.0.0 is removed. Shader preloading still runs in the background as before.

## Updating from 1.0.1

Extract 1.0.2, open **Hyrule Warriors AOI Recomp Optimized Compiler.exe**, choose the same NUP and output folder, and click **Compile / update**.

- The shader translator changed, so the game retranslates its shaders once on the first launch. Expect a longer first load.
- Saves and settings are kept.

## Using it

Download the ZIP below, extract all of it, open **Hyrule Warriors AOI Recomp Optimized Compiler.exe**, choose your own game NUP and an output folder, then click **Compile / update**. Nothing else needs installing.

> Bring your own matching game files. This ZIP contains no game, keys, firmware or artwork.

## Frame rate

90 and 120 FPS can be selected, but **they speed up the whole game (1.5× / 2×)**. For smooth motion at normal speed, play at **60 FPS** with frame generation such as Lossless Scaling LSFG 2×.

## Requirements

- Windows 10/11 x64, an AVX2 CPU and a Vulkan GPU (32 GiB RAM recommended)
- At least 20 GiB of free space for the output
- Hyrule Warriors: Age of Imprisonment, title 04003F40232DE000, version 1.0.3 (NCM 196608), as a NUP
